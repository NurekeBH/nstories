# ApiPay.kz — лендинг

Kaspi Pay төлемдерін автоматтандыратын ApiPay сервисіне арналған сату лендингі.
Тәуелділіксіз: таза HTML + CSS + JS (build қажет емес).

## Құрылымы

```
landing/
├── index.html          # барлық секция (әдепкі тіл — қазақша)
└── assets/
    ├── styles.css      # стильдер (түстер :root айнымалыларында)
    ├── i18n.js         # орысша аударма (KZ мәтіні HTML-де)
    └── app.js          # тіл ауыстыру, мәзір, қойындылар, FAQ, есептегіш, форма
```

## Екі тіл: қазақша / орысша

Бетте KZ / RU ауыстырғышы бар (header-де және мобильді мәзірде).

- **Қазақша** мәтін — `index.html` ішінде, `data-i18n="кілт"` атрибутымен белгіленген.
  Яғни JavaScript өшірулі болса да, бет қазақша толық көрінеді (SEO үшін де жақсы).
- **Орысша** аударма — `assets/i18n.js` ішіндегі `ru` объектісінде, сол кілттермен.
- Таңдалған тіл `localStorage` ішінде сақталады, `<html lang>`, `<title>`,
  `description` және `og:` мета-тегтері де ауысады.

Мәтінді өзгерткенде екі жерді де түзетіңіз: HTML-дегі қазақша нұсқа және
`i18n.js`-тегі орысша нұсқа (кілттер бірдей болуы керек).

Браузер тілі орысша болса, бетті бірден орысша ашқыңыз келсе —
`assets/app.js` ішіндегі `CONFIG.AUTO_LANG` мәнін `true` етіңіз.

## Жергілікті іске қосу

```bash
cd landing && python3 -m http.server 8000
# → http://localhost:8000
```

Хостингке (Vercel, Netlify, nginx, кез келген static hosting) `landing/` папкасын сол күйінде жүктесеңіз жеткілікті.

## Жариялау алдында ауыстыру керек

`index.html` ішінде `АУЫСТЫРЫҢЫЗ` деген түсініктемелер қалдырылған:

- байланыс деректері (телефон, e-mail, WhatsApp, Telegram);
- кабинетке кіру және құжаттама сілтемелері;
- `og:image` суреті;
- «Көрсеткіштер» блогындағы сандар — нақты статистикаңызбен;
- Құпиялылық саясаты / оферта сілтемелері.

Кодтағы `https://api.apipay.kz/v1/invoices` мысалдарын ресми құжаттамадағы
нақты эндпоинт пен өріс атауларымен салыстырып шығыңыз.

## Лид формасын жалғау

`assets/app.js` ішіндегі `CONFIG.FORM_ENDPOINT` мәніне өз бэкендіңіздің
(немесе CRM вебхугының) мекенжайын жазыңыз. Бос болса, форма тек
«рақмет» экранын көрсетеді, ал дерек консольге шығады.

Есептегіштің шартты эквайринг мөлшерлемесі мен тариф лимиттері де сол
`CONFIG` блогында — қажет болса өзгертіңіз.

## Баптау

Түс палитрасы — `assets/styles.css` файлының басындағы `:root` блогында.
Негізгі бренд түсі: `--brand: #FF4438`.

Жаңа тіл қосу үшін `i18n.js` ішіне жаңа объект (мысалы `en`) қосып,
header-дегі `.lang` блогына `data-lang="en"` батырмасын қосыңыз.
